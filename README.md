# 🐾 毛球寵物店 3D

在瀏覽器裡經營一間寵物店的 3D 網頁遊戲：進貨、照顧寵物、看街上流行、擺設裝潢、雇用店員、擴建店面，一直經營下去。

**立即遊玩：https://jhou12345600-lang.github.io/pet-shop-3d/**

- 14 種寵物（倉鼠、米格魯、大貓熊、長頸鹿、大象……還有夢幻寵物）
- 每種寵物有專用飼料和最愛罐頭，生病要對症下藥
- 男女店員會自己結帳、餵食、清便便、補貨、陪寵物玩
- 手機、電腦都能玩；存檔存在自己的瀏覽器裡

原創致敬作品，所有角色與美術皆為原創。使用 [three.js](https://threejs.org/)（MIT）。
